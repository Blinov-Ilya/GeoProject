# RSRP около культурных объектов Вены

Проект оценивает наружный радиосигнал около пяти культурных объектов Вены по данным учебных драйв-тестов. Основной показатель — RSRP, dBm. После очистки осталось 577 474 измерения операторов A, B и C.

## Материалы проекта

1. `vienna_analysis.ipynb` — notebook для повторного запуска: очистка, геокодирование Яндексом, пространственные расчёты и экспорт результатов. Сохранённые результаты предыдущего расчёта находятся в `output/`.
2. `qgis/vienna.qgz` — карта с шестью содержательными слоями; все данные находятся в `qgis/data/`. Для просмотра без QGIS — `qgis/vienna_map.pdf`.
3. `superset/superset_dashboard.zip` — экспорт четырёх блоков Superset. Изображения dashboard находятся в той же папке.
4. `reports/methodology.pdf` — методология, 3 страницы.
5. `reports/ai_report.pdf` — отчёт об использовании ИИ, 1 страница.

Редактируемые исходники отчётов — соседние `.md`. Таблицы, результаты геокодирования и счётчики очистки — в `output/`.

Готовые архивы для сдачи: `deliverables/submission.zip` — полный комплект; `deliverables/qgis_project.zip` — отдельно проект QGIS с данными.

Локальный dashboard: http://localhost:8088/superset/dashboard/vienna-rsrp/

## Как посмотреть результаты

Культурные объекты: Technisches Museum, Raimund Theater, Secession, Theater an der Wien и Upper Belvedere. Их адреса и ответы Яндекса сохранены в `output/objects.csv` и `output/geocoding.json`.

Оценка около объекта — медиана RSRP в радиусе 250 м отдельно для каждого оператора, минимум по трём записям. Это измерения на окружающих улицах, а не внутри здания.

Карта посвящена оператору A. Из слоя H3 resolution 9 получен оценочный растр с пикселем 100 м; перенос значений ограничен расстоянием 250 м от поддерживающих измерений. Вне оценки остаётся NoData. Точки, H3-медианы и число измерений можно включить в панели слоёв. Шесть содержательных слоёв открываются без интернета; онлайн-подложка OpenStreetMap требует соединения. PDF уже содержит подложку.

В Superset доступны все три оператора. Выберите значения в фильтре «Оператор» и нажмите Apply filters. В таблице есть прокрутка. ZIP содержит настройки dashboard и datasets; соответствующие CSV находятся в `output/`.

## Как повторить расчёты

Откройте notebook из папки проекта и выполните ячейки по порядку. Он содержит весь код подготовки и не зависит от вспомогательных Python-скриптов. Для локального Python 3.11 библиотеки перечислены в `requirements.txt`.

Исходный файл ищется в `data/vienna_drive_test.csv` и `../data/vienna_drive_test.csv`. Если CSV не распакован, notebook читает его прямо из `deliverables/submission.zip`, включённого в репозиторий. Уже очищенный `output/measurements.csv` не подменяет исходные данные.

Для Google Colab разместите папку проекта в файловой системе среды рядом с notebook. При необходимости перейдите в папку проекта командой `%cd /content/GeoProject`, подставив свой путь, затем выберите «Среда выполнения → Выполнить всё». Первая ячейка ищет уже размещённые файлы в текущей папке и соседних `project` / `GeoProject`. Ручная распаковка CSV не требуется. Если после установки библиотек Colab попросит перезапустить среду, перезапустите её и снова выполните все ячейки.

Установочная ячейка использует NumPy 2.x (`numpy>=2.1,<3`) и не понижает его до 1.26. Если вы уже запускали старую ячейку с `numpy<2`, перед повторной проверкой выберите «Среда выполнения → Отключиться и удалить среду выполнения», затем подключитесь заново и выполните актуальный notebook. Это восстановит исходный набор библиотек Colab; после удаления среды папку проекта потребуется разместить в ней заново.

При наличии корректного `output/geocoding.json` ключ API и обращения к геокодеру не нужны. Для нового геокодирования добавьте `YANDEX_API_KEY` в Secrets Colab или локальный `.env`, который не следует сдавать вместе с проектом. При недоступном сервисе, отсутствующем ключе, повреждённом кэше или неправильном CSV notebook выводит подсказку и пропускает зависимые этапы. Проверки качества данных сохраняются: CSV и GeoPackage экспортируются только после успешной проверки расчётов и построения растра. Итоговая таблица показывает состояние каждого этапа; после исправления проблемы повторите «Выполнить всё».
